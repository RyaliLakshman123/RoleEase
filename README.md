# RoleEase

RoleEase is an AI-powered iOS career companion built with SwiftUI.

It combines AI career guidance, interviews, resume analysis, job discovery, and recruiter communication into one focused experience.

Built with modern Apple technologies to simplify and improve career preparation.

## Features

- 🤖 AI Career Assistant
- 🎤 AI Mock Interviews
- 🗣️ Voice-based career assistance
- 📄 Resume analysis and ATS-focused feedback
- 💼 Job discovery
- ✉️ AI-powered recruiter email generation
- 🧭 Career roadmap and guidance
- 💬 Streaming AI chat experience

## Technology Stack

### iOS Development

- Swift
- SwiftUI
- SwiftData
- Xcode
- iOS 26
- Liquid Glass design

### AI & Networking

- AI-powered career workflows
- Server-Sent Events (SSE) for streaming AI responses
- URLSession for networking
- On-device OCR for document and resume processing

### Subscriptions

- RevenueCat
- Monthly and annual subscription plans
- Premium entitlement management

### Backend

RoleEase communicates with a private backend service for AI-powered functionality.

The backend source code, server-side API keys, and private credentials are not included in this repository.

## Getting Started

1. Clone this repository.
2. Open `RoleIQ.xcodeproj` in Xcode.
3. Configure the required API and backend settings for your local environment.
4. Configure RevenueCat using your own development credentials if subscription functionality is required.
5. Select an iOS Simulator or connected device.
6. Build and run the application.

> The production backend and private credentials are not included in this repository.

## Design

RoleEase uses a modern SwiftUI interface designed around Apple's latest design language, with focused experiences for AI chat, interviews, resumes, jobs, and career planning.

## Monetization

RoleEase uses RevenueCat to manage subscriptions and premium entitlements, with monthly and annual subscription options.
